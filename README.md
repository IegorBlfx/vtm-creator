# Створення персонажа · Вампіри: Маскарад 5

Покроковий конструктор персонажа для гравців «Vampire: The Masquerade» 5-ї редакції українською.
Статичний сайт: HTML + CSS + чистий JavaScript, без збірки, без фреймворків і без бекенду.

## Як викласти

Скопіюйте вміст папки на будь-який статичний хостинг або веб-сервер, нічого не збираючи:
nginx/Apache, GitHub Pages, Netlify, Cloudflare Pages, S3 тощо.

- Точка входу — `index.html`.
- Шляхи відносні, тож сайт працює і в корені домену, і в підпапці (`/vtm/`).
- Перевірити локально: `python3 -m http.server` у цій папці → http://localhost:8000.
  Подвійний клік по `index.html` теж працює, але PDF тоді буде без портрета клану (браузер не пускає локальні файли в canvas).

## Структура

```
index.html            розмітка каркаса (шапка, кроки, нижня панель)
css/style.css         усі стилі, темна тема, друк (@media print)
js/app.js             логіка: кроки, правила, підказки, збереження, PDF
js/data/*.js          довідники з книги (клани, сили, переваги, словник…)
img/art/<клан>.jpg    портрети кланів (9 шт., ~100 КБ кожен)
```

Скрипти підключені звичайними `<script>`, не модулями, у фіксованому порядку: спершу `js/data/*`, останнім `app.js`.
Дані лежать у глобальному об’єкті `window.VTM`. Щоб поправити текст чи правило, змініть відповідний файл у `js/data/`, перебудовувати нічого не потрібно.

## Зовнішні залежності

| Що | Звідки | Коли |
| --- | --- | --- |
| Шрифти Cormorant Garamond, Inter | fonts.googleapis.com, fonts.gstatic.com | при завантаженні сторінки |
| html2canvas 1.4.1, jsPDF 2.5.1 | cdnjs.cloudflare.com | лише при натисканні «Зберегти PDF» |

Якщо на сайті налаштована Content-Security-Policy, дозвольте:

```
script-src  'self' https://cdnjs.cloudflare.com;
style-src   'self' 'unsafe-inline' https://fonts.googleapis.com;
font-src    https://fonts.gstatic.com;
img-src     'self' data: blob:;
```

`'unsafe-inline'` у `style-src` потрібен, бо розмітка генерується з атрибутами `style`. Inline-скриптів і обробників `on…` у коді немає.

Без інтернету все працює, крім PDF (шрифти тоді замінюються системними).

## Дані користувачів

- Нічого не надсилається на сервер.
- Прогрес зберігається в `localStorage` браузера під ключем `vtm5-character-v1`.
- Гравець може зберегти персонажа у файл `.vtm.json` і завантажити його назад. Файл при завантаженні перевіряється й очищається від невідомих значень.
- «Зберегти PDF» генерує лист A4 у браузері; «Друк» відкриває стандартний діалог друку.

## Підтримка браузерів

Сучасні Chrome, Edge, Firefox, Safari (десктоп і мобільні). Потрібні ES2018+ (зокрема lookbehind у регулярних виразах — Safari 16.4+).
